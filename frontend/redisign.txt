DIREÇÃO VISUAL — HELENA AUGUSTA

Criar o website da Helena Augusta Comunicação com estética editorial, sofisticada, minimalista e contemporânea.

A referência estética é uma mistura de:
- luxury editorial
- fashion magazine
- boutique communications agency
- contemporary Brazilian lifestyle
- arquitetura e design
- fotografia cinematográfica

IMPORTANTE:
Não copiar o layout ou identidade visual da Karla Otto. Usar apenas como referência de sofisticação, minimalismo e experiência digital.

==================================================
1. PALETA DE CORES
==================================================

Usar uma paleta quente, sofisticada e pouco saturada.

COR PRINCIPAL — OFF-WHITE
HEX: #F1EAE1
RGB: 241, 234, 225
Uso:
- background principal
- áreas de conteúdo
- header
- cards claros

COR SECUNDÁRIA — AREIA
HEX: #E6E0D6
RGB: 230, 224, 214
Uso:
- backgrounds alternativos
- cards
- separações de seção

COR TAUPE
HEX: #8B8378
RGB: 139, 131, 120
Uso:
- textos secundários
- pequenos detalhes
- metadata
- labels

COR OLIVA ESCURO
HEX: #262419
RGB: 38, 36, 25
Uso:
- grandes blocos de destaque
- cards de clientes
- seções especiais
- backgrounds escuros

COR PRETO PROFUNDO
HEX: #100F09
RGB: 16, 15, 9
Uso:
- títulos
- textos principais
- navegação
- elementos de alto contraste

COR MARROM CAFÉ
HEX: #634C35
RGB: 99, 76, 53
Uso:
- pequenos detalhes
- hover
- elementos de apoio

COR TERRACOTA QUEIMADO
HEX: #8D6A4A
RGB: 141, 106, 74
Uso:
- acentos muito pontuais
- nunca usar como cor dominante

PROPORÇÃO APROXIMADA DA PALETA:

70% — #F1EAE1
15% — #100F09
8% — #262419
5% — #E6E0D6
2% — #8D6A4A / #634C35

Não utilizar cores vibrantes, neon, branco puro (#FFFFFF) ou preto absoluto (#000000).

16. FOTOGRAFIA
==================================================

A fotografia é extremamente importante.

Não utilizar banco de imagens com aparência corporativa.

Direção:

- editorial
- cinematográfica
- natural
- sofisticada
- brasileira
- lifestyle
- fashion
- arquitetura
- design
- natureza
- gastronomia
- hotelaria
- detalhes humanos
- textura
- luz natural

Color grading:
- quente
- levemente desaturado
- contraste moderado
- pretos não completamente pretos
- aparência de filme analógico
- evitar cores vibrantes

Evitar:
- pessoas olhando para a câmera sorrindo
- reuniões corporativas
- apertos de mão
- notebooks
- escritórios genéricos
- stock photography óbvia

==================================================
17. MICROINTERAÇÕES
==================================================

Animações devem ser discretas.

Usar:
- fade
- slow reveal
- slight image zoom
- horizontal slide
- underline animation

Duração:
400–700ms

Easing:
cubic-bezier(0.22, 1, 0.36, 1)

Evitar:
- efeitos exagerados
- parallax excessivo
- animações rápidas
- elementos pulando
- estética tecnológica

18. RESPONSIVIDADE
==================================================

DESKTOP:
1440px / 1280px

TABLET:
768–1024px

MOBILE:
320–767px

No mobile:
- reduzir H1 para 46–56px
- H2 para 38–44px
- padding lateral 24px
- transformar grids em coluna
- manter bastante espaço negativo
- preservar a hierarquia editorial

IMPORTANTE:

O layout principal deve ser pensado PRIMEIRO para desktop.

Não criar uma versão mobile que pareça simplesmente uma redução da versão desktop.
